# ABAS SATHI Version 5.4 — Release Notes

**Tagline:** Smart Living. Better Community.

## মূল আপডেট

### 1. Quick Login
- Society Code ও Login ID ঐচ্ছিকভাবে এই browser/device-এ মনে রাখা যায়।
- Password কখনও remembered-login storage-এ রাখা হয় না।
- Login form double-submit আটকায় এবং progress indicator দেখায়।
- Backend response timeout ও unreadable response-এর জন্য স্পষ্ট error handling যোগ হয়েছে।
- Reload-এর পর protected dashboard দেখানোর আগে server-এর `getMyProfile` দিয়ে session validate হয়।
- Backend প্রতি authenticated request-এ account status ও role যাচাই করে; সেই নিরাপত্তা বজায় আছে।
- Active session ব্যবহার করলে backend ও client-side expiry sliding six-hour TTL অনুযায়ী refresh হয়।
- Logout request navigation-এর আগে পাঠানো হয় এবং local session clear করা হয়।

### 2. Quick Live Save / Upload
- Idempotency ledger-সমর্থিত write action-এ transient network/5xx failure হলে একই `requestId` দিয়ে একবার retry হয়।
- Ambiguous retry-তে duplicate record/payment/file তৈরির ঝুঁকি কমে।
- Save retry কেবল operation-ledger সমর্থিত action-এ সীমাবদ্ধ; সব API-তে অন্ধ retry করা হয় না।
- Google Sheets Central Master matching এখন row-by-row service call না করে batch read ব্যবহার করে।
- Drive upload-এর আগে related record, category/module mapping, permission, property/owner relation এবং target document column যাচাই করা হয়।
- Resident payment proof এখন payment record তৈরি হওয়ার পরে সেই Transaction_ID-এর সঙ্গে Drive-এ upload/link হয়।
- Activity Request ও Expense form-এ double-submit prevention এবং save/upload progress text যোগ হয়েছে।
- Save success কেবল backend success response-এর পরে দেখানো হয়।

## Database compatibility
- Existing society sheets, sheet names, business fields এবং existing account/password hash format অপরিবর্তিত।
- No required database migration.
- Existing password hashes remain supported; successful legacy login hash upgrade behaviour remains unchanged.
- Central Master, society-specific Spreadsheet IDs, Drive Folder IDs এবং Apps Script Script Properties আগের মতোই ব্যবহার হবে.

## Security notes
- Password browser storage-এ সংরক্ষণ করা হয় না।
- Remembered login option কেবল Society Code ও Login ID রাখে।
- Password verification, role authorization এবং society isolation server-side-এই থাকে।
- Existing localStorage session token design বজায় রাখা হয়েছে backward compatibility-এর জন্য; এটি HttpOnly cookie নয় এবং XSS-এর বিরুদ্ধে browser-accessible token ঝুঁকি সম্পূর্ণ দূর করে না। Production security review-এ CSP/XSS prevention ও session storage strategy আলাদাভাবে যাচাই করুন।

## Important limitations
- Google Apps Script `fetch` upload progress শতাংশ সরবরাহ করে না; UI stage/status দেখায়, byte-level percentage নয়।
- Drive ও Sheets একই distributed transaction নয়। Pre-validation এবং idempotency আছে, কিন্তু Google Drive/Sheets-এর মধ্যে true atomic commit নেই। কোনো service failure-এ `_Operation Ledger`, `_File Registry` এবং সংশ্লিষ্ট record পরীক্ষা করে reconciliation করতে হতে পারে।
- Actual Vite build, browser regression, deployed Apps Script, live Google Sheets/Drive, all-role and cross-society tests must pass in the owner's staging environment before production use.
