# ABAS SATHI Version 5.3.1 — Release Notes (বাংলা)

**Release type:** Development / pilot hardening build. **এটি এখনও Production-Ready certification নয়।**

## এই সংস্করণে বাস্তব কোড পরিবর্তন

1. **Selective module loading:** Frontend আর `getSocietyData` bulk API ব্যবহার করে না। Active screen অনুযায়ী `getModuleData`-এ module request পাঠায়; প্রতিটি module-এর pagination page ধরে পড়ে। Backend-এ unfiltered non-Resident reads সরাসরি প্রয়োজনীয় row range পড়ে। Filtered/Resident reads এখনও sheet scan করতে পারে।
2. **Invoice:** Backend-এ rate, active property, current ownership, billing period, rate effective date, selected-property mapping এবং net amount যাচাই করে invoice write করা হয়। একই property/rate/period-এর non-cancelled duplicate invoice আটকানো হয়।
3. **Payment:** Server-generated receipt number, positive amount validation, current ownership check, same-property invoice validation, duplicate payment reference check এবং idempotency ledger যোগ হয়েছে। Payment confirmation-এ invoice outstanding, bill-wise allocation, receipt status ও bank balance server-side update হয়।
4. **Expense:** Server-generated voucher number; expense `Pending Approval` হিসেবে তৈরি হয়; UI-এর “Approve & Pay” action backend-এ role-checked, locked bank-balance debit ও Paid transition করে। Paid expense cancellation বন্ধ; reversal entry আলাদা accounting process হিসেবে করতে হবে।
5. **CRUD API foundation:** Property, Owner, Ownership, Rate, Expense Category, Bank Account, Activity Request, Notice, Gallery, Preventive Maintenance, Rate Property Mapping, Property Utility, FY, Tenant ও Account Head-এর জন্য server-side create/update/soft-cancel endpoints যোগ হয়েছে। Audit Log ও financial registers generic CRUD দিয়ে edit করা যায় না।
6. **Role/property scope:** Backend write endpoints-এ role checks, resident property checks এবং activity request ownership checks আছে। Resident reads current ownership period-এ সীমাবদ্ধ করা হয়েছে।
7. **Private files:** PDF/JPG/PNG, 5 MB limit, society-specific private folder, hidden `_File Registry` mapping এবং registry-checked download endpoint যোগ হয়েছে। Payment Proof upload UI-তে বাস্তব file input যোগ হয়েছে।
8. **Backup:** Society Admin-এর জন্য society spreadsheet copy endpoint এবং Apps Script owner-এর জন্য manual `backupCentralMasterManual()` helper যোগ হয়েছে।
9. **Configuration:** Central Master Spreadsheet ID ও default Drive Folder ID source code থেকে সরিয়ে Apps Script Script Properties-এ নেওয়া হয়েছে। Login response থেকে database Spreadsheet ID বাদ দেওয়া হয়েছে।
10. **Audit/idempotency:** `_Operation Ledger` hidden sheet-এ write operation ID/status/result রাখা হয়; app API-তে Audit Log write করা হয়।

## Owner-এর একবারের সেটআপ

Apps Script Editor → **Project Settings** → **Script Properties**-এ যোগ করুন:

| Property | Value |
|---|---|
| `CENTRAL_MASTER_SPREADSHEET_ID` | Central Master Google Spreadsheet ID |
| `DEFAULT_DRIVE_FOLDER_ID` | Private root Drive folder ID |

Central Master-এর `Society Master` tab-এ প্রতিটি society row-তে `Society_Code`, `Society_Status`, `Database_ID`, `Society_Name` এবং সম্ভব হলে `Drive_Folder_ID` থাকতে হবে। Society-specific Drive folder ID দিলে সেটিই ব্যবহৃত হবে; না থাকলে private root-এর ভিতরে `Society_<CODE>` folder তৈরি হবে।

প্রতিটি society spreadsheet-এ exact tab names ও headers থাকতে হবে। বিশেষত `Invoice_Register` বা `Invoice Register`—দুটির যেকোনো একটি সমর্থিত। `Audit Log`, `Bank Account Master`, `Ownership History`, `Property Master`, `Owner Master`, `Fund Inflow Register`, `Bill Wise Details`, `Expense Register` অবশ্যই থাকতে হবে।

## গুরুত্বপূর্ণ সতর্কতা

- Google Sheets বহু-sheet write-এর জন্য database transaction/rollback দেয় না। `_Operation Ledger` operation `STARTED` রেখে দেয় যদি মাঝপথে failure হয়; এটি duplicate retry আটকায়, কিন্তু স্বয়ংক্রিয় rollback নয়। Admin/Accountant-কে ledger ও register মিলিয়ে recovery করতে হবে।
- All modules-এর screen-level create/edit forms এখনও তৈরি বা সংযুক্ত নয়। Generic API আছে, কিন্তু Property/Owner/Rate/Bank/Category/Tenant/Utility/Gallery/Preventive Maintenance/Financial Year/Account Head UI workflows সম্পূর্ণ নয়।
- Invoice generation-এর বর্তমান frontend flow একবারে একটি property invoice করে; bulk monthly invoice generator এখনও সম্পূর্ণ নয়।
- Payment proof upload বাস্তব; অন্য document categories-এর upload API আছে, কিন্তু সব screen-এ file picker/download UI যুক্ত হয়নি। Upload failure-এর পর orphan file cleanup manual।
- Backup endpoint spreadsheet copy তৈরি করে; automatic schedule, retention policy, one-click restore এবং backup integrity verification নেই। Central Master backup owner Apps Script থেকে manual run করতে হবে।
- Audit Log app API-তে update/delete route নেই; Google Sheet owner/editor permissions দিয়ে কেউ সরাসরি edit করলে Apps Script তা ঠেকাতে পারে না।
- Live Apps Script/Drive/Sheets integration, role penetration test, concurrency stress test, real browser test এবং GitHub Pages deployment এখানে চালানো হয়নি।

## Deployment

1. `apps_script/Code.gs` সম্পূর্ণ কপি করে Apps Script project-এ দিন।
2. Script Properties সেট করুন; প্রয়োজনীয় Google authorization দিন।
3. Web App হিসেবে Deploy করুন: Execute as **Me**; access **Anyone** (GitHub Pages static frontend-এর জন্য)।
4. `/exec` URL ABAS SATHI Settings-এ configure করুন; প্রয়োজনে `src/utils/authClient.ts`-এর default URL update করুন।
5. `npm install`, `npm test`, `npm run lint`, `npm run build` local machine-এ চালান।
6. Test Society spreadsheet-এ প্রথমে payment, invoice, expense, resident access এবং private file tests করুন। Production financial use-এর আগে manual backup নিন।

## Rollback

- পুরনো GitHub commit/tag-এ frontend rollback করুন।
- Apps Script → Deploy → Manage deployments থেকে আগের deployment version পুনরায় deploy করুন।
- Sheet migration destructive নয়; `_Operation Ledger` ও `_File Registry` hidden tabs রেখে দিন। Financial rows delete বা পুরনো backup দিয়ে overwrite করবেন না।
- Partial `STARTED` operations থাকলে আগে সংশ্লিষ্ট invoice/payment/expense/bank rows reconcile করুন; তারপরই retry/rollback করুন।
