# ABAS SATHI Version 5.3.2 — Release Notes (বাংলা)

## এই সংস্করণে যুক্ত হয়েছে

### ১. Master Data CRUD
- Settings → Master Data CRUD-এ role অনুযায়ী module selector।
- Property, Owner, Ownership History, Rate, Expense Category, Bank Account, Tenant, Activity Request, Notice, Gallery, Preventive Maintenance, Rate Property Mapping, Property Utility, Financial Year এবং Account Head-এর Create/Edit/Archive।
- User Master-এর জন্য AdminUsersView-এ Edit এবং Active/Inactive controls।
- Server-side schema, role validation, field allowlist, audit log ও basic duplicate/reference validation।
- Ownership History archive/delete করা হয় না; End Ownership করলে `Ownership_Status=Previous` এবং `Ownership_End_Date` সেট হয়।
- Owner Master-এ archive support-এর জন্য `Owner_Status` column না থাকলে backend সেটি যোগ করে; current ownership থাকা Owner archive করা যায় না।
- Financial fields যেমন Current_Balance, Paid_Amount, Outstanding_Amount, Receipt_Number, Voucher_No এবং Invoice_Number generic CRUD দিয়ে বদলানো যায় না।

### ২. Private Document Center
- Settings → Documents-এ private upload ও download।
- Category: Owner Document, Expense Voucher, Gallery Photo, Notice Attachment, Activity Request Attachment, Payment Proof, Invoice PDF।
- PDF/JPG/PNG, সর্বোচ্চ 5 MB।
- File Registry-তে Drive File ID, property, owner, category, uploader এবং related record reference।
- Owner document, expense voucher, gallery, notice, activity request, payment proof এবং invoice-এর file reference সংশ্লিষ্ট sheet column-এ যুক্ত করার ব্যবস্থা।
- Activity Request form ও Expense form-এ file upload control।
- Resident KYC file download কেবল নিজের KYC file-এ সীমাবদ্ধ; Admin KYC file যাচাই/ডাউনলোড করতে পারেন।
- Notice attachment ও gallery image private file API দিয়ে পড়া হয়; public Drive link ব্যবহার করা হয় না।

### ৩. Backup, Restore ও Recovery
- Admin manual backup।
- Admin daily backup trigger enable/disable করতে পারবেন।
- Daily trigger আনুমানিক রাত ২টায় Central Master ও Active Society spreadsheet-এর private Drive copy তৈরি করে।
- Restore-এর আগে live spreadsheet-এর pre-restore copy তৈরি হয়।
- Restore backup file-টি একই society-এর Backup Log এবং private folder-এর মধ্যে আছে কি না যাচাই করে।
- Incomplete `_Operation Ledger` operations-এর recovery queue UI।
- Restore-এর পর `_Restore Log` ও Audit Log-এ record লেখা হয়।

### ৪. Reports ও Balance Sheet
- Server-side Receipt & Payment, Financial Year, Property Outstanding, Owner Outstanding, Expense Summary ও Balance Sheet report APIs।
- Invoice generation: Dr Accounts Receivable / Cr Income।
- Confirmed payment: Dr Bank / Cr Accounts Receivable + Resident Advances।
- Paid expense: Dr Expense / Cr Bank।
- Unpaid invoice cancellation-এর জন্য reversal journal entry।
- One-time balanced opening balance journal batch।
- Accountant Balance Sheet snapshot submit করবেন; অন্য Admin SHA-256 hash যাচাই করে approve করবেন।
- Balance Sheet internal system-generated report; independent statutory audit নয়।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- Google Apps Script/Sheets multi-sheet ACID transaction দেয় না। `STARTED` operation দেখলে blindly retry করবেন না।
- পুরনো invoices/payments/expenses স্বয়ংক্রিয়ভাবে `_Journal Ledger`-এ backfill হয় না।
- Daily backup retention/rotation স্বয়ংক্রিয় নয়; Drive storage পর্যবেক্ষণ করতে হবে।
- Central Master-এর backup automated হয়, কিন্তু এই UI-তে Central Master restore নেই।
- Restore backup-এ অনুপস্থিত newer internal tabs মুছে ফেলা হয় না; restore-এর পরে workbook compare করতে হবে।
- Live Google authorization, production build এবং GitHub Pages deployment এই build environment-এ সম্পন্ন হয়নি।
