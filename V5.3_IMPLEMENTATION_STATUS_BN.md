## সতর্কতা

এই release-এ `getSocietyData` compatibility action এখনও সব module একসঙ্গে পড়ে, কারণ Version 5.2-এর screens এখনও এই data shape-এর উপর নির্ভরশীল। নতুন selective endpoint আছে, কিন্তু UI-এর প্রতিটি screen এখনও সেটি ব্যবহার করে না। তাই বর্তমান package-কে পূর্ণ selective-loading performance release বলা যাবে না।

`getDashboardSummary`-এর বর্তমান summary হলো প্রাথমিক operational summary; এটি audited financial statement, balance sheet বা accounting ledger-এর বিকল্প নয়।

**প্রস্তাব:** এই package কেবল development/staging environment-এ deploy করুন। প্রকৃত society-র financial entry চালু করবেন না, যতক্ষণ না উপরের অসম্পূর্ণ financial workflows ও live integration tests শেষ হচ্ছে।
