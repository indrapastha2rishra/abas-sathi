# ABAS SATHI v5.6.3 — Login Lookup Acceleration Report (বাংলা)

## পরিবর্তন
- Apps Script `ScriptCache`-এ Society Code এবং Society Code + Login ID-এর **row number index** সর্বোচ্চ ৫ মিনিট রাখা হয়।
- প্রতিবার login-এ cached row-এর live sheet row পড়ে Society Code/Login ID মিলিয়ে যাচাই করা হয়।
- Cache stale/invalid হলে আগের TextFinder fallback চলে।
- Password/hash, profile, Database_ID, token বা credential cache করা হয়নি।
- Existing password KDF (12,000 HMAC-SHA256 rounds), account active check, role, tenant/society isolation এবং session rules unchanged।
- Existing successful-login activity metadata write এখনও asynchronous, তাই এটি login response block করে না।

## Performance limitation
This is a source-level optimization. It reduces repeat-login lookup scanning. It cannot promise under 1 second: Google Apps Script cold start/network latency, Spreadsheet service latency, and the secure 12,000-round password verification are still in the login path. Do not reduce the password KDF or bypass server authentication to make the UI appear logged in.

## Release status
**Staging candidate — not production-certified.** Before production, install dependencies, run `npm ci`, `npm test`, `npm run lint`, `npm run build`; deploy the updated Apps Script as a new version; then measure at least 20 warm and 10 cold login attempts on real devices/network and inspect only privacy-safe timing logs.
