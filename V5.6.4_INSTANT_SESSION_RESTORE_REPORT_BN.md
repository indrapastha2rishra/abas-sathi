# ABAS SATHI v5.6.4 — Instant Returning Session Restore (বাংলা রিপোর্ট)

## কী পরিবর্তন করা হয়েছে
- আগের saved session token ও local expiry valid থাকলে React-এর initial state-এ session restore করা হয়; কোনো backend request-এর আগে Login screen আর দেখানো হয় না।
- `getMyProfile` verification background-এ চালানো হয়। App shell rendering-এর জন্য verification response অপেক্ষা করে না।
- Successful server verification profile fields update করে এবং session expiry refresh করে।
- Confirmed `AUTH_ERROR` হলে local session clear করে Login-এ ফেরত যায়।
- Network/server failure হলে saved session local-এ রাখা হয় এবং Offline/Server unavailable banner দেখায়; retry ও sign-out option থাকে।
- Browser online/offline event-এর ভিত্তিতে banner/status পরিবর্তন এবং online হলে background verification retry হয়।
- Backend data operations এখনও server token validation-এর উপর নির্ভরশীল; offline writes অনুমোদন করা হয় না।

## Expected behavior
- Returning user-এর saved session থাকলে App shell network response-এর অপেক্ষা ছাড়াই render হবে; target: 1 second-এর মধ্যে visible shell, device/browser performance অনুযায়ী।
- First-time login, expired local session, অথবা local session নেই এমন user-এর Login process আগের secure server verification ব্যবহার করবে; slow internet-এ 1-second guarantee নেই।
- Offline অবস্থায় এটি offline cached ledger/data application নয়। App shell/UI দেখায়; live Sheets data load এবং server writes network/backend ছাড়া কাজ করবে না।
