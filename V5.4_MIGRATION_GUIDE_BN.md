# ABAS SATHI Version 5.4 — Migration & Deployment Guide (বাংলা)

## ১. Database migration
Version 5.4-এর জন্য কোনো existing business sheet rename/delete করতে হবে না এবং কোনো নতুন required business sheet/column যোগ করা হয়নি। Existing Central Master, Society Code, Database Spreadsheet ID, Drive Folder ID এবং Apps Script Script Properties অপরিবর্তিত রাখুন।

## ২. GitHub update
1. বর্তমান repository-র backup/branch তৈরি করুন।
2. Version 5.4 ZIP extract করে project files repository-তে update করুন।
3. `.github/workflows/deploy.yml`, `deploy.yml`, `.gitignore`, `vite.config.ts`, `index.html` এবং GitHub Pages configuration অকারণে পরিবর্তন করবেন না।
4. `apps_script/Code.gs`-এর সম্পূর্ণ Version 5.4 source ব্যবহার করুন।
5. `package.json`-এ version `5.4.0` আছে যাচাই করুন।
6. GitHub-এ commit/push করুন।
7. GitHub Actions workflow সফল হয়েছে কিনা দেখুন। Build failure হলে production deploy করবেন না।

## ৩. Google Apps Script update
1. আগের Apps Script project খুলুন—নতুন project তৈরি করবেন না।
2. `Code.gs`-এর সম্পূর্ণ পুরনো code backup করে রাখুন।
3. Version 5.4 ZIP-এর `apps_script/Code.gs` দিয়ে সম্পূর্ণ code replace করুন।
4. Project Settings → Script Properties-এ আগের `CENTRAL_MASTER_SPREADSHEET_ID` এবং `DEFAULT_DRIVE_FOLDER_ID` অপরিবর্তিত আছে নিশ্চিত করুন। এগুলো source code বা frontend-এ লিখবেন না।
5. Save করুন; Apps Script editor-এ syntax error নেই নিশ্চিত করুন।
6. Deploy → Manage deployments → existing Web App deployment → Edit।
7. Version dropdown থেকে New version নির্বাচন করুন।
8. Execute as: Me এবং access setting আগের approved configuration অনুযায়ী রাখুন।
9. Deploy করুন; existing `/exec` URL অপরিবর্তিত আছে নিশ্চিত করুন। URL বদলালে frontend config-এ নতুন URL update করতে হবে।
10. Google permission prompt এলে project owner হিসেবে প্রয়োজনীয় authorization দিন।

## ৪. Quick Login acceptance
- চারটি role দিয়ে আলাদা আলাদা test login করুন।
- Remember Society Code/Login ID চালু/বন্ধ করে দেখুন।
- Browser storage-এ Password রাখা হয়নি নিশ্চিত করুন।
- Reload-এর পর server session validation হয় নিশ্চিত করুন।
- Logout-এর পরে পুরনো token দিয়ে API request ব্যর্থ হচ্ছে নিশ্চিত করুন।
- inactive user এবং expired session protected screen ব্যবহার করতে পারছে না নিশ্চিত করুন।

## ৫. Live Save / Upload acceptance
Staging society database-এ property create/update, invoice, payment, receipt, expense, activity request, notice, owner document এবং gallery photo পরীক্ষা করুন। প্রত্যেকটির ক্ষেত্রে Google Sheet row, operation ledger, File Registry এবং private Drive folder যাচাই করুন। একই operation-এর retry-তে duplicate row/file তৈরি হচ্ছে না নিশ্চিত করুন।

## ৬. Production gate
সব role, all modules, multi-society isolation, browser responsive checks এবং live Drive/Sheets upload tests সফল না হওয়া পর্যন্ত production financial use শুরু করবেন না। Apps Script/Sheets/Drive একাধিক service হওয়ায় true atomic transaction সম্ভব নয়; `_Operation Ledger`-এ STARTED অবস্থায় থাকা operation থাকলে record/Drive/File Registry পরীক্ষা করে reconcile করুন।
