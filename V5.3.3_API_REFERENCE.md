# ABAS SATHI Version 5.3.3 — API Change Reference

## Added report type
Existing endpoint/action: `getReports`
New `reportType`: `ownershipOutstanding`

### Request body
```json
{
  "action": "getReports",
  "token": "<session token>",
  "requestId": "<unique request id>",
  "reportType": "ownershipOutstanding"
}
```

### Response shape
```json
{
  "status": "success",
  "reportType": "ownershipOutstanding",
  "data": [
    {
      "Ownership_ID": "OWN-001",
      "PropertyID": "PROP-001",
      "Flat_No": "A-101",
      "OwnerID": "OWNER-001",
      "Owner_Name": "Example Owner",
      "Ownership_Start_Date": "2025-04-01",
      "Ownership_End_Date": "",
      "Ownership_Status": "Current",
      "Invoice_Count": 2,
      "Total_Billed": 1200,
      "Total_Paid": 300,
      "Outstanding": 900,
      "Data_Link_Status": "Linked"
    }
  ],
  "summary": {
    "ownershipCount": 1,
    "totalOutstanding": 900,
    "unlinkedInvoiceCount": 0
  }
}
```

The example values are illustrative. Actual response values come from the requesting society's sheets.

### Data source and rules
- `Invoice_Register` supplies invoice ownership, amount, paid and outstanding fields.
- `Ownership History` supplies ownership period and status.
- `Property Master` supplies flat number fallback.
- `Owner Master` supplies owner name fallback.
- Group key: `Ownership_ID`.
- Cancelled invoices and invoices with no positive outstanding are excluded.
- If `Outstanding_Amount` is blank, the report falls back to `max(0, Net_Charge_Amount - Paid_Amount)`.
- Invoices with blank `Ownership_ID` are grouped by property and owner into `Not linked` and counted in `summary.unlinkedInvoiceCount`.
- Authorization remains Admin / Accountant / Committee as in `getReports_`; Resident access is denied.
